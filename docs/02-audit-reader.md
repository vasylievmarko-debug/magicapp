# Аудит входящих экранов — сторона Reader + сквозные проблемы маркетплейса

Вход: `input/initial-screens/MR Reader Journeys/` — 22 борда, 10 модулей + Master Handoff.
Сторона User — см. `01-audit-user.md`.

## 0. Что это за вход

- Тот же формат, что у User: растровые борды 1536×1024, всё «APPROVED / LOCKED», версии v1.0 и v2.0 вперемешку.
- **Master Handoff** называет себя *«the single source of truth for all reader portal features»* — и при этом противоречит остальным бордам (см. раздел 4). Лучшая цитата для статьи.

## 1. Что сделано хорошо (берём как основу)

- **Ошибки с причиной и действием**: Payout Failed показывает «Invalid account details» + что делать; Moderation Rejected — конкретное нарушение + Edit & Resubmit.
- **Модерация медиа**: проверка до публикации, правила контента (без контактов, без вводящего в заблуждение контента), статусы Live / Pending / Private / Rejected.
- **Block / Report** с причинами и историей жалоб. Пример «Can we talk on WhatsApp?» — верно пойманный реальный риск ухода с платформы.
- **Прозрачность заработка** по сессии: ставка, длительность, чаевые, комиссия, итог.
- Pre-live проверка камеры/микрофона/сети; Pause account с выбором срока; Deactivate с вводом слова для подтверждения.
- Hide vs Unpublish vs Delete — правильное разделение обратимых и необратимых действий.

## 3. Критично: безопасность, этика, legal

| # | Проблема | Где |

| R-E2 | **Нет модерации live-чата**: гадалка не может замьютить/удалить зрителя во время эфира (блок есть только в личных сообщениях) | Live Streaming |

## 4. Навигация и IA

- **~7 вариантов нижней навигации** у гадалки:
  1. Dashboard · Calendar · Messages · Earnings · Profile — Master, Earnings, Settings
  2. Dashboard · Bookings · [Orb] · Messages · Menu — Dashboard Journey
  3. Dashboard · Calendar · [Orb] · Messages · Profile — Availability
  4. Dashboard · Bookings · [Orb] · Messages · Profile — Booking B1
  5. Dashboard · Calendar · Bookings · Messages · Profile — Booking B2, Messages B1
  6. Dashboard · Messages · Earnings · Profile — Profile Management
  7. Dashboard · Messages · [Orb] · Bookings · Profile — Live Streaming B3
- **Нумерация модулей не совпадает**: в Master «03 Live Streaming, 04 Availability, 06 Bookings…», а в названиях Developer Pack — Live = 02, Availability = 03, Booking = 05. Dashboard в Master — 02, в паке — 01.
- **Четыре механизма «я недоступна»**: Online/Offline toggle, Availability slots, Holiday Mode, Pause Account. Как они взаимодействуют — нигде.
- **Два разных Availability**, оба APPROVED: v1.0 (недельный вид, есть явные «Offline» слоты) и v2.0 (месячный, «unavailable by default»).
- **Уведомления в двух местах**: колокольчик в шапке и Notification Centre внутри Messages.
- Master обещает в шапке «Country selector» — его нет ни на одном экране.
- Time zone: «(GMT+1) London» и «(GMT+0) Dublin, Lisbon, London» в одном списке.

## 5. Онбординг

- **Верификация в двух версиях**: онбординг — Passport/ID + Proof of address; профиль — Identity, Document, Background check, Phone.
- **Порядок противоречит**: онбординг заканчивается «Verification in Progress → Go to Dashboard», а Dashboard First Login снова просит «Verify your identity».
- **Специализации**: 6 в онбординге (Love, Career, Finance, Spiritual Guidance, Astrology, Tarot), другие 8+ в профиле (Twin Flame, Manifestation, Energy Healing, Past Life…), третий набор — в фильтре клиента.
- В онбординге **нет настройки цены и способа выплат** — гадалка «одобрена», но заработать не может.

## 6. Консистентность и артефакты генерации

- **Одна гадалка — пять имён**: Chanty, Luna Mystic, «Chanterella Kkkkee @chanterella», Chantelle F., и на live-стриме — визуально другой человек.
- Слоганы: «Live psychic readings» vs «Face to face with fate».
- Опечатки и мусорный текст: «live wnd», «reivew», «Wore Options», «live eession», «Info Icon Gnaqra», наложение текста на Choose Thumbnail.
- Брейкпоинты: 320–767 / 768–1024 / 1025+ (Master) vs 375–480 / 768–1024 / 1280+ (остальные).
- Web или app? «Cross browser tested (Chrome, Safari, Firefox, Edge)» vs push на экране блокировки iOS.

## 8. Сквозные проблемы маркетплейса (User × Reader)

Самое ценное в аудите — то, что видно только при сравнении двух сторон.

| # | Проблема | Почему критично |
|---|---|---|
| X1 | **Экономика не сходится**. Клиент покупает 250 Auras за £3.99 (≈ £0.016/Aura), гадалка получает £0.10/Aura. Платформа доплачивает ~6× на каждой Aura | Бизнес-модель невозможна в таком виде |
| X2 | **Ключевой момент продукта не нарисован ни с одной стороны**: переход из публичного эфира в приватную сессию. Клиент: 3 разных флоу; гадалка: карточка запроса → Accept → *пустота* → «Broadcast Ended, Private Readings: 2» | Главный монетизируемый сценарий отсутствует |
| X3 | **Приватность «private / 1:1» нарушена с обеих сторон**: клиент видит чат других, гадалка видит «LIVE · 24 viewers» | Прямое противоречие обещанию продукта |
| X4 | **Модель цены**: гадалка задаёт одну цену за минуту для видео и аудио; клиент видит фиксированные пакеты (5–20 мин), сессии по 15/30 мин и 5+ разных цен | Разработчики не смогут реализовать биллинг |
| X5 | **Таксономия** специализаций/тем разная в онбординге, профиле гадалки и фильтре клиента | Поиск и матчинг ломаются |
| X6 | **Политика отмены / no-show / возврата** упоминается, но не определена ни на одной стороне | Споры и потеря доверия с обеих сторон |
| X7 | **Таблицы уведомлений** на бордах каждой стороны не совпадают (напр., напоминание 24h vs 1h) | Нет единой матрицы событий |
| X8 | **Одна персона на две роли**: «Chantelle» — и клиент, и гадалка | Признак того, что модель данных не продумана |
| X9 | Инструменты безопасности у гадалки (block/report) есть; **симметричные у клиента — проверить** | Защищена должна быть каждая сторона |

## 9. Вывод

Со стороны Reader AI сделал больше «взрослых» вещей (модерация, выплаты, ошибки с причинами), но проблема та же: **каждый борд — отдельная правдоподобная картинка без общей модели**. При сравнении сторон это превращается из косметики в продуктовые дыры: экономика не сходится, а ключевой сценарий маркетплейса — приватная сессия — не спроектирован вообще.
